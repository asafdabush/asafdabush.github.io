Highlighted Projects

Terahertz Ellipsometry Measurement System

B.Sc. final project • 2026 • Grade 95

Designed, built and calibrated a variable-analyzer-angle THz ellipsometer around a THz-TDS core, with a full MATLAB processing chain (windowing, FFT, per-bin harmonic fit, drift correction, bootstrap uncertainties, thin-film inversion). Validated on silicon with no calibration offset (β = −0.997 vs. −1, Δ = −0.64° vs. 0°, R² = 0.968), then applied to FePS₃. Also built a LabVIEW-controlled closed-loop motion stage with 0.4 µm/step resolution.

  • THz-TDS
  • Jones calculus
  • MATLAB
  • LabVIEW
  • Motion control

Repository & report

TW DALI LED Module

2026 • Personal hardware project

Ø50 mm two-channel tunable-white LED driver designed end to end in KiCad. Two AL8860 constant-current bucks (≈ 667 mA each) are dimmed by an STM32G0 through PWM or DAC. An optically isolated DALI interface uses a current-limited receiver and a MOSFET bus-shorting transmitter, behind a dedicated isolation keep-out band. The 24 V input has reverse-polarity, PTC and TVS protection.

  • DALI DT8
  • STM32

POOPCAT: Radar-Triggered Ultrasonic Repeller

2026

A 24 GHz mmWave radar triggers a 40 kHz ultrasonic burst. An ESP8266 hardware timer generates a complementary carrier and a TC4427 drives the piezo array differentially (10.3 Vpp at 41.3 kHz, measured). The non-blocking firmware state machine runs with Blynk remote control and WiFi failover.

Parkinson’s Disease EEG Analysis

2026

Developed a comprehensive pipeline for processing resting-state EEG data to aid the diagnosis of Parkinson’s disease. Preprocessed raw EEG signals (resampling, filtering, artifact removal, FastICA), extracted features using higher-order statistics and other measures, and classified segments using SVM and bagged decision trees. Best result: Bagged Trees on the full band, 93.8% accuracy and AUC 0.998 (segment-level 10-fold CV).

  • MATLAB
  • EEGLAB
  • ICA & Higher-order statistics
  • Machine Learning (SVM & Bagged Trees)
